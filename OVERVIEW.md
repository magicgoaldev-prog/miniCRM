# Как устроен SiteFlow (для руководителя)

SiteFlow — небольшая система для стройки. Постановщик заводит объекты (площадки) и задачи по ним, назначает исполнителей. Исполнитель видит только свою работу, берёт задачу, делает и отдаёт на проверку. Постановщик принимает результат или возвращает на доработку с комментарием.

По статусам задача ходит так: новая → в работе → на проверке → принята. С проверки можно вернуть на доработку, тогда исполнитель снова переводит её в работу. Других «перескоков» нет — система их не пропускает.

Данные защищены не только кнопками на экране. Правила записаны в базе. Даже если кто-то обойдёт интерфейс и обратиться к базе напрямую, чужие задачи исполнитель не прочитает и не изменит. Статус меняется только по разрешённым шагам. Историю статусов через обычный доступ не подделать, не поправить и не стереть. Сами зарегистрироваться нельзя — учётки заводит администратор. Секретные ключи с полным доступом к базе в сайт не попадают.

Коротко, чего исполнитель сделать не может: открыть чужую задачу, сменить чужой статус, принять работу за постановщика, подправить историю проверки или завести себе новый аккаунт через приложение.
